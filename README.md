# Vico Dark Pro

A modern, high-contrast dark theme designed specifically for JetBrains IDEs, featuring a deep black editor background (`#0F0F0F`) and seamless integration with the New UI **Islands Dark** layout.

![Vico Dark Pro Preview](https://raw.githubusercontent.com/sirvico/vico-dark-pro/main/screenshot.png)

## Features

- **Deep Black Editor:** Built around an immersive `#0F0F0F` background optimized for C11/C17 and modern multi-language development.
- **Islands UI Integration:** Fully compatible with JetBrains New UI floating panels, rounded modular containers, and clean visual separation.
- **Refined Selection:** Clean, discrete blue/grey selection highlights in the Project Tree and tool windows to prevent visual fatigue and maintain focus.
- **Custom Accent Palette:** Subtle purple/magenta highlights for active indicators, focus rings, and important UI elements.

## Installation

### From JetBrains Marketplace (Recommended)
1. Open your JetBrains IDE (e.g., CLion, IntelliJ).
2. Go to **Settings / Preferences** > **Plugins** > **Marketplace**.
3. Search for **"Vico Dark Pro"** and click **Install**.
4. Restart the IDE and select the theme under **Appearance & Behavior** > **Appearance**.

### Manual Installation (From Disk)
1. Download the latest `vico-dark-pro.jar` release from the [Releases page](https://github.com/sirvico/vico-dark-pro/releases).
2. Open **Settings / Preferences** > **Plugins** > click the **Gear icon (⚙️)** > **Install Plugin from Disk...**
3. Select the downloaded `.jar` file and restart the IDE.

## Requirements

- Compatible with JetBrains IDEs version **2023.1 and newer** (New UI enabled).
